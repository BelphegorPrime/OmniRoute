- **fix(sse):** Gemini tool schemas no longer put `items` on a non-array node: a type union that carries `items` now flattens to `array` (or to `object` when it carries `properties`), and an untyped node with `items` is typed `array`, avoiding the Gemini 400 `items: field predicate failed: $type == Type.ARRAY` (#18146).
